# 📝 explication

Une application web complète de gestion de tâches (To-Do List) permettant de planifier, suivre et organiser des activités par ordre de priorité chronologique.

## 🚀 Fonctionnalités
- **Tableau de bord** : Visualisation des tâches sous trois colonnes (À faire, En cours, Terminées).
- **Planification par date** : Saisie d'une date de commencement pour chaque tâche.
- **Tri intelligent** :
  - *À faire* : Tri chronologique de la plus proche à la plus lointaine.
  - *Terminées* : Tri chronologique inverse (dernières tâches finies en haut).
- **systeme d'authentification** : Accès sécurisé via un page de creation de compte et une page de connexion.

## 🛠️Technique
- **Frontend** : Vue.js 3, HTML5, CSS3.
- **Backend** : Flask (Python), Flask-CORS.
- **Base de données** : MySQL.
- **Conteneurisation** : Docker.
